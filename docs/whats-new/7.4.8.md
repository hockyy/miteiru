# What's New in Miteiru 7.4.8

Changes since [v7.4.7](https://github.com/hockyy/miteiru/releases/tag/v7.4.7).

## Improvements
- The meaning box is much more compact:
  - The pitch accent indicator moved out of the sticky header into the scrollable body as a slim "Pitch accent" section (one row per headword variant).
  - "My Notes" is now a collapsible accordion — closed by default when no note exists, open when a saved note is present; Add note / Edit / AI generate open it automatically.
  - The inflection table moved to the bottom of the meaning box and collapses into an accordion showing just the form count when closed.
  - "Quick actions" is a single row: the W / Shift+W shortcut hints now live inside the copy buttons.

**Full Changelog**: https://github.com/hockyy/miteiru/compare/v7.4.7...v7.4.8
