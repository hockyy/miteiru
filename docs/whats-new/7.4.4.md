# What's New in Miteiru 7.4.4

Changes since [v7.4.3](https://github.com/hockyy/miteiru/releases/tag/v7.4.3).

## Fixes

- **Local video loading** — Restored reliable Windows video playback after the Next.js port with a range-aware `miteiru://` protocol.
- **Seeking and streaming** — Added byte-range responses and correct media content types for local video files.

## Developer notes

- Added end-to-end video loading diagnostics for normalized paths, player lifecycle events, stalls, errors, and protocol responses.
- Added tests for Windows path resolution and HTTP byte-range parsing.

**Full Changelog**: https://github.com/hockyy/miteiru/compare/v7.4.3...v7.4.4
