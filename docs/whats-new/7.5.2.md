# What's New in Miteiru 7.5.2

Changes since [v7.5.1](https://github.com/hockyy/miteiru/releases/tag/v7.5.1).

## Features
- LRCLIB lyrics search (sidebar, **M**, command palette) works in normal playback, not only karaoke mode. Karaoke mode is still the scrolling-lyrics display.
- Searching lyrics for a YouTube video uses yt-dlp to fetch the video title as the default query.
- Downloaded YouTube lyrics are saved as `yt_{videoId}.lrc`. Opening that video again loads the saved lyrics automatically.

## Fixes
- Pinyin / furigana ruby sits in the **middle** of the characters underneath. Chromium was still left-aligning the reading even after `ruby-align: center`.

**Full Changelog**: https://github.com/hockyy/miteiru/compare/v7.5.1...v7.5.2
