# What's New in Miteiru 7.4.5

Changes since [v7.4.4](https://github.com/hockyy/miteiru/releases/tag/v7.4.4).

## Fixes

- **YouTube link handling** — Video ID extraction now works for Shorts, embed, and `youtu.be` links with extra query parameters (fixes lyrics lookup for those URLs), and lookalike domains such as `youtuXbe` no longer pass the YouTube check. Mobile (`m.youtube.com`) links are now accepted too.
- **File detection** — Uppercase extensions like `MOVIE.MKV` or `SUBS.SRT` are now recognized, and Windows paths like `C:\videos\movie.mp4` resolve their file name correctly.
- **Anki card HTML injection** — Subtitle text containing HTML metacharacters is now escaped in ruby markup and dictionary definitions, so crafted subtitle files can no longer inject markup into the meaning box, card previews, or exported Anki cards.
- **Video player clock** — Negative timestamps no longer render as `00:-5`, and word-age colors stay valid for future-dated entries.
- **Next-file navigation** — Folders now sort naturally (`ep1, ep2, …, ep10`) instead of lexicographically (`ep1, ep10, ep2`).
- **Byte-range edge case** — Suffix range requests against empty files now correctly return 416 instead of an invalid 206.

## Developer notes

- Added a universal dictionary JSON Schema (`main/dictionary/dictionary.schema.json`) covering any BCP-47 language, with dedicated subschemas for Japanese (`kanji`/`kana`/`kanjiInfo`), Mandarin (`simplified`/`traditional`/`pinyin`), and Cantonese (`jyutping`).
- Added a dependency-free validator (`main/dictionary/validateDictionary.ts`) with structured error paths, plus an ajv parity test suite proving it agrees with the JSON Schema.
- Test suite grew from 16 to 24 files (207 tests): utils, mediaUtils, meaningEntries, sentenceRuby, parseJsonResponse, getSubtitles SRT parsing, dictionary validator, and schema parity.
- Exported the pure SRT/language-matching helpers from `main/helpers/getSubtitles.ts` for testability.
- Added `ajv` as a devDependency for schema parity testing.
