# What's New in Miteiru 7.4.6

Changes since [v7.4.5](https://github.com/hockyy/miteiru/releases/tag/v7.4.5).

## Features

- **Japanese pitch accent coloring** — The meaning box now shows a pitch accent indicator for Japanese headwords: a mora-by-mora high/low reading strip with a downstep marker, plus a pattern pill (平板 / 頭高 / 中高 / 尾高) with the accent number. Words with multiple accepted accents show switchable pills. Data comes from [Kanjium](https://github.com/mifunetoshiro/kanjium) (CC BY-SA 4.0) and covers ~10,300 word/reading pairs (nouns and compounds; verb/adjective conjugation accents are not included yet).

## Fixes

- **Japanese language asset pack** — The published `japanese-assets.zip` was missing the grammar catalog (`jp_grammar.json`), so a fresh asset download silently broke grammar study. The pack has been rebuilt and re-uploaded with the grammar data (and the new pitch accent data) included.

## Developer notes

- Added `scripts/buildPitchAccentData.js` (`npm run script:build-pitch-accent`) which extracts accent positions from the Kanjium SQLite database into `renderer/public/language-assets/japanese/pitch/accents.json`; the Japanese asset manifest now lists it.
- Added `renderer/utils/pitchAccent.ts` (mora splitting, accent classification, lookup with kana normalization) with unit tests.
- Added a GitHub Actions release workflow (`.github/workflows/release.yml`): pushing a `v*` tag (or publishing a release) builds Windows NSIS + portable, macOS pkg, and Linux deb/AppImage (22.04 and 24.04) artifacts and attaches them to the GitHub release automatically.
