# What's New in Miteiru 7.4.7

Changes since [v7.4.6](https://github.com/hockyy/miteiru/releases/tag/v7.4.6).

## Features
- Redesigned the Japanese pitch accent indicator with an OJAD-style contour graph: a line over per-mora dots shows the high/low pitch pattern, and a hollow particle dot disambiguates heiban (particle stays high) from odaka (particle drops). Pattern pills now have English tooltips and a clear active state.

## Fixes
- Release installers now bundle the language asset payloads (dictionaries, tokenizers, kanji SVGs). The v7.4.6 CI builds were missing them because the payloads are gitignored and the workflow never downloaded them — dictionary lookup and tokenization were broken in those installers.
- Fixed a React `key` warning in the meaning box header and invalid `<rt>`-inside-`<rt>` HTML nesting in subtitle ruby rendering.

## Developer notes
- Added load success/failure unit tests for subtitle parsing (SRT/ASS/LRC/HUF) and the `miteiru://` video protocol (range parsing, 200/206/416 responses). Suite: 244 tests.
- The release workflow now runs `npm run script:download-language-assets` before building.

**Full Changelog**: https://github.com/hockyy/miteiru/compare/v7.4.6...v7.4.7
