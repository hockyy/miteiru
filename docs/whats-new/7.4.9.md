# What's New in Miteiru 7.4.9

Changes since [v7.4.8](https://github.com/hockyy/miteiru/releases/tag/v7.4.8).

## Fixes
- Release build reliability:
  - Language asset downloads now retry up to 3 times with backoff (a single socket hang-up failed the v7.4.7 linux-22.04 build).
  - The asset-list API call authenticates with the workflow token (unauthenticated calls share a 60 req/hr pool per runner IP and 403'd the v7.4.8 macOS build twice).
  - Unpacking language assets no longer wipes the plugin directory first, which could delete git-tracked files (grammar data, pitch accents) when extracting a stale archive.

No app code changes — same features as v7.4.8.

**Full Changelog**: https://github.com/hockyy/miteiru/compare/v7.4.8...v7.4.9
