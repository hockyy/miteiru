# What's New in Miteiru 8.0.0

Changes since [v7.6.3](https://github.com/hockyy/miteiru/releases/tag/v7.6.3).

Miteiru 8 is rebuilt on [Tauri](https://tauri.app) and [mpv](https://mpv.io). It no longer ships its own copy of Chromium: the interface runs in the system's webview, a small Rust core handles files, processes and storage, and video plays through libmpv.

## Plays nearly any video, without converting
- **Any file mpv plays opens directly:** MKV, MP4, HEVC (including 10-bit), AV1, DTS, AC-3 and the rest, with hardware decoding where the system has it.
- **The "convert this video" prompt is gone.** Files with several audio tracks show a short list to pick from instead, and switching is instant.
- Subtitles inside the video are still read through FFmpeg and become clickable, as before.

## The same app, on a new base
- **Your data carries over.** Miteiru 8 uses the same data folder as 7.x, so your words, notes, Anki settings and preferences are still there. Learning data moves into a new SQLite store the first time you open it; the old copy is left untouched.
- **Each language rebuilds its dictionary database once** the first time it loads after updating (a few seconds).
- **Full screen:** F11 (Ctrl+Cmd+F on macOS). **Ctrl + / Ctrl −** zoom the interface.
- The window opens at the size and position you left it.
- Links that open a new window go to your browser.
- **Miteiru updates itself from now on** on Windows, macOS and the Linux AppImage. A few seconds after it starts it offers a new version, and you choose when to restart. You can turn this off under Settings & tools → Updates. Coming from 7.x, you still download 8.0 once yourself.
- The [analyzer API](../ANALYZER_SERVER.md) for other tools keeps the same endpoints, token and `analyzer-server.json`.

## Downloads
- **Windows:** `Miteiru_8.0.0_x64-setup.exe`.
- **macOS (Apple silicon):** `Miteiru_8.0.0_aarch64.dmg`, replacing the `.pkg`. Still not notarized: [open it anyway](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unidentified-developer-mh40616/mac).
- **Linux:** `Miteiru_8.0.0_amd64.deb` and `.AppImage`, built on Ubuntu 22.04. Video plays through the system's libmpv: the `.deb` installs it; for the AppImage, install `libmpv2` (`libmpv1` on Ubuntu 22.04).
- On Windows, Miteiru 8 installs beside 7.x rather than over it; uninstall 7.x afterwards if you like. Your data stays either way.
