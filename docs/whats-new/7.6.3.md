# What's New in Miteiru 7.6.3

Changes since [v7.6.2](https://github.com/hockyy/miteiru/releases/tag/v7.6.2).

## Fixes
- **Homebrew media tools are detected on macOS** ([#107](https://github.com/hockyy/miteiru/issues/107)). Miteiru checks `/opt/homebrew/bin` on Apple Silicon and `/usr/local/bin` on Intel Macs when a tool is missing from PATH, including when launched from Finder. This applies to yt-dlp, FFmpeg, and FFprobe, both in settings and when running the tools.
- **Local video sources use the correct media type.** MP4, MOV, and other containers are no longer all declared as WebM.
- Local video URLs use an explicit host so Chromium preserves the full filesystem path on macOS.
- Local videos with spaces, Japanese characters, `#`, `?`, or `%` in their filenames load through correctly escaped URLs.
- Tool checks time out after ten seconds if an executable stops responding.
