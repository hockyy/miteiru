# What's New in Miteiru 7.5.1

Changes since [v7.5.0](https://github.com/hockyy/miteiru/releases/tag/v7.5.0).

## Features
- **Live Captions on Apple Silicon Macs** — On macOS 26+, Live CC uses the system live-captions engine (computer audio) and feeds the same tokenized overlay as Windows. Home shows Live CC as available; video and learn get the CC Live control.
- First start may ask for **Screen & System Audio Recording** (grant **Electron** in `npm run dev`, or **Miteiru** for the `.pkg`). Live CC uses the language loaded on the home screen (Japanese, Mandarin, or Cantonese); Apple may download that language pack on first use. Vietnamese is not supported by Apple Live Captions.

## Developer notes
- Native helper `native/live-captions/mac/` is built by `npm run dev` (`--if-needed`) and by `npm run build` / `npm run build:macos`, then bundled in the Mac `.pkg`.
- Live CC support is Apple Silicon + Darwin 25+ (macOS 26 Tahoe). Intel Macs and older macOS still report unavailable.
